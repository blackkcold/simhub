# Android 管理中心 UI/UX · v0.16.0

## 导航与视觉边界

- SIM 节点：青绿色主题，本机状态/本机短信/SIM/设置。
- 管理中心：靛紫色主题，总览/加密短信/远程设备/管理设置。
- 同一 Compose Shell，管理中心不得引入第二套底栏或嵌套 WebView。
- 管理中心总览包含原生计数卡片、快捷操作和 Relay 的持久任务状态；设备详情为全屏原生内容，保留状态/权限/通道/远程同步/诊断/OTA。
- 新增管理图标均有 design/icons SVG 源文件和 Android VectorDrawable；测试保持路径一致。
- 设备危险操作、共享池及 Vault 密钥恢复仍从 HTTPS 高级管理进入，以避免复制未经测试的密码学和管理员授权操作。本版本不宣称这些高风险流程已经完整原生化。

## 短信能力矩阵

| 节点状态 | 本机发送 UI | 原生管理中心远程发送 | Web 管理中心发送 |
| --- | --- | --- | --- |
| Android 不接管/companion（默认） | 隐藏编辑器，显示只读说明 | 不显示发送，保留短信读取及同步 | 不显示发送 |
| Android 完全接管/default + SEND_SMS 授权 | 展示编辑器 | 满足在线、未撤销、有效通道后展示 | 允许 |
| Android 完全接管/default，但无发送权限 | 隐藏编辑器 | 不显示发送 | 不显示发送 |
| Android companion + 开发者 1 小时临时强制发送 + SEND_SMS | 显示并警示仅供测试 | 显示开发者测试身份和警示 | 仅显式上报 smsDeveloperOverride 才可显示 |
| 独立 Modem 节点 | 不适用 | 根据 modem 运营状态及通道判断 | 同步判断 |
| 离线/撤销/重置中/无 SIM 通道 | 本机视系统条件 | 禁止远程发送 | 远程发送受限 |

这是 **UI 准入规则**，并非替代设备端实际能力验证：
Android 发送时继续使用 `SmsSendPolicy.requireCanSend`；节点权限、SIM 通道、Channel Revision 与命令幂等性由节点和服务端分别校验。测试授权会自动超时，到期后节点拒绝发送，管理端可能因状态上报延迟暂时保留旧 UI，不能将排队状态宣传为发送成功。

## 其他保证

- 使用既有管理终端签名认证、共享 Global Vault 和 E2EE 加密。
- 原生远程命令创建采用随机 commandId、idempotencyKey 和有效期；以持久 ACK 为最终状态来源。
- SMS 会话内回复仅预填收件人，绝不推断或自动切换来源 SIM；用户必须核对发送设备/通道。
- Passkey 及用户授权继续复用同手机上的可信 HTTPS 浏览器。
- 本机系统身份验证仅是访问门禁，不是每次 Vault 解密均要求硬件 Keystore 认证。
- 部署前必须完成模拟器、真机、折叠屏、深浅色、中英文、较大字体、网络中断、Doze/离线与 SMS 两种模式测试。软件 CI 不能视为真机认证。
